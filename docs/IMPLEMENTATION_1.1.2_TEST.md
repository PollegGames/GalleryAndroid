# Galerie 1.1.2-test

Cette branche sert uniquement à produire l’APK de validation sur appareil avant la version finale.

Corrections visées :

- explorateur de déplacement hiérarchique depuis Téléphone et Carte SD ;
- partage simple et multiple sans titre de fichier ajouté par l’application ;
- URI partagées également fournies dans `ClipData` pour permettre l’aperçu système ;
- lecteur interne d’images et vidéos ;
- commandes du lecteur masquées ou réaffichées par un toucher ;
- masquage automatique pendant la lecture vidéo ;
- actions Partager, Déplacer et Supprimer depuis le lecteur ;
- identification visible de la build `1.1.2-test`.
